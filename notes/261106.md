## HTML 이력서를 PDF로 자동으로 만들기 (Puppeteer)

### 한 줄 요약
이력서를 HTML로 관리하고, **헤드리스 브라우저(화면 없이 돌아가는 크롬)** 로 열어 `page.pdf()`를 부르면 매번 같은 모양의 PDF가 나온다. 손으로 "인쇄 → PDF 저장"을 반복할 필요가 없다.

### 왜 어려웠나
- 회사마다 이력서를 고칠 때마다 PDF를 다시 뽑아야 했고, 사이트에 올리는 공개용 PDF와 HTML도 매번 맞춰야 했다.
- 스크립트를 임시 폴더에 두었더니 폴더가 비워져 `Cannot find module`이 두 번 났다.
- PDF에서 한국어 단어가 중간에 끊기거나, 표·제목이 쪽 경계에서 잘렸다.

### 개념 정리

```
resume.html ──▶ Puppeteer(헤드리스 크롬)
                  1) launch()            브라우저 켜기
                  2) page.goto(file://…)  HTML 열기, 폰트·이미지 다 받을 때까지 대기(networkidle0)
                  3) page.pdf({format:'A4', margin, printBackground})
                ──▶ resume.pdf
```

```js
// scripts/generate-pdf.js
const puppeteer = require('puppeteer');
(async () => {
  const [input, output] = process.argv.slice(2);
  const browser = await puppeteer.launch({ headless: 'new' });
  const page = await browser.newPage();
  await page.goto(/^https?:/.test(input) ? input : `file://${input}`, { waitUntil: 'networkidle0' });
  await page.pdf({ path: output, format: 'A4', margin: { top: '14mm', right: '14mm', bottom: '14mm', left: '14mm' }, printBackground: true });
  await browser.close();
})();
```

| 문제 | 원인 | 해결 |
|---|---|---|
| 웹폰트가 안 나옴 | 폰트를 받기 전에 PDF를 찍음 | `waitUntil: 'networkidle0'` |
| 배경색·회색 상자가 사라짐 | 인쇄 기본값은 배경을 빼고 찍음 | `printBackground: true` |
| 한국어 단어가 중간에서 끊김 | 기본 줄바꿈이 글자 단위 | CSS `word-break: keep-all` |
| 제목만 쪽 끝에 남고 내용은 다음 쪽 | 쪽 나눔을 신경 안 씀 | `@media print { h3 { break-after: avoid } table { break-inside: avoid } }` |
| 스크립트가 사라짐 | 임시 폴더에 둠 | 저장소 안 `scripts/`에 두기 |
| `Cannot find module 'puppeteer'` | 스크립트 위치에 라이브러리가 없음 | 설치된 프로젝트에서 실행하거나 `NODE_PATH` 지정 |

- 쪽수 확인: PDF 파일 안의 `/Type /Page` 개수를 세면 몇 쪽인지 바로 알 수 있다.
- 링크 확인: PDF 안의 `/URI (...)`를 뽑으면 링크가 제대로 들어갔는지 볼 수 있다.

### 내 프로젝트에서는
- `private_resume/scripts/generate-pdf.js` 하나로 이력서 2쪽, 경력기술서 3쪽, 회사별 이력서, 토스플레이스 포트폴리오 PDF까지 만들었다.
- 사이트용은 같은 HTML에서 PDF를 만들어 `portfolio/public/`에 복사한다. 그래서 사이트에서 받는 PDF와 제출용 PDF가 항상 같다.
- 포트폴리오 사이트의 "상세 링크가 메인으로 간다"는 의심이 있었을 때, PDF 안의 링크 주소를 뽑아 모두 각 프로젝트 주소인 것을 확인했다.

### 면접에서 이렇게 말하기
> 이력서와 경력기술서를 HTML로 관리하고, Puppeteer로 PDF를 자동으로 만들었습니다. 회사마다 내용만 바꾸면 같은 스크립트로 같은 모양의 PDF가 나오고, 사이트에 올리는 공개용 PDF도 같은 원본에서 만들어 서로 어긋나지 않게 했습니다. 폰트 대기, 배경 출력, 한국어 줄바꿈, 쪽 나눔 같은 인쇄 문제는 옵션과 print CSS로 해결했습니다.

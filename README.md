# study

실무와 면접 준비를 하며 **어렵다고 느낀 것**을 그날그날 정리하는 저장소입니다.

- 시작일: 2026-11-04
- 파일 이름: `notes/YYMMDD.md` (예: `notes/261104.md`)
- 하루에 여러 주제가 나오면 같은 파일에 `##` 제목으로 이어 씁니다.

## 노트 형식

1. **한 줄 요약**: 결국 무엇인지
2. **왜 어려웠나**: 헷갈린 지점
3. **개념 정리**: 그림이나 표로 쉽게
4. **내 프로젝트에서는**: 실제로 겪거나 쓴 곳 (없으면 생략)
5. **면접에서 이렇게 말하기**: 30초 답변
6. **스스로 확인 질문**: 다음에 다시 볼 때 답해보기

## 티스토리

- `*.md`: 티스토리 마크다운 모드에 붙여넣기
- `*.html`: 티스토리 HTML 모드에 붙여넣기 (표·코드 블록이 깨지지 않음)
